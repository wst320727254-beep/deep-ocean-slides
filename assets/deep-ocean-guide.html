00 · OVERVIEW这套风格是什么

命中学术风设计分支（学术可信 / 证据驱动 / 蓝白克制），叠加自选的 Deep Ocean 冷调配色。核心判断标准：像论文，不像海报。

维度取值
风格 DNA学术可信 · 撑满优先 · 证据化配图 · 卡体克制 · 层次清楚 · 色彩受控
适用场景课题组组会、文献汇报、开题/中期、学术会议、学科评估、教学课件（理工医）
不适用产品发布、营销方案、政务党建、儿童/卡通、需要强情绪煽动的场合
情绪基调克制、冷静、可信、专业。不做营销感，不用大留白当风格
页面节奏Hero 页 4/12（封面 / 主效应 / 关键发现 / 结尾），peak–valley 交替，无连续 3 页 valley
版式策略非对称版式 10/12（83%），对称版式仅封面与结尾 2 页；等宽 N 卡片横排 = 0
一条总原则：内容页必须"撑满"——内容区累计高度 ≥ 476px（本项目实际做到 430–440px 卡片 + 上下留边），元素不得集中在画布中央 60% 区域。留白是封面/结尾的专利，不是正文页的风格手段。

08 · TUTORIAL在别处复刻这套风格

路线 A · PowerPoint（推荐，换算最直接）

1
设画布
设计 → 幻灯片大小 → 宽屏 (16:9)。即 13.333×7.5 英寸，与 1280×720px 1:1。
2
建主题色
设计 → 变体 → 颜色 → 自定义颜色。依次填入：深色1 #1B3A5C、着色2 #2E9BA6、着色3 #6B86A3、强调 #C0392B、浅色 #F4F7FB/#E6F3F5。命名保存为「Deep Ocean」。
3
建主题字体
设计 → 变体 → 字体 → 自定义。中文「思源黑体 / 微软雅黑」，西文「Inter / Arial」。
4
做幻灯片母版
视图 → 幻灯片母版。画 60px 高深蓝顶条（1280×60 ≈ 宽 13.33in × 高 0.625in），左侧放 8×8px 青绿方块，底部画 40px 页脚区 + 1px 分隔线，右下角插页码占位符。关闭母版视图后所有页自动继承。
5
拖参考线
视图 → 参考线。加水平线 60 / 140 / 200 / 640 / 680 px（换算 in：0.625 / 1.458 / 2.083 / 6.667 / 7.083），垂直线 40 / 1240 px（0.417 / 12.917 in）。
6
按逐页表摆元素
照第 06 节坐标表，用「大小和位置」窗格精确填 x/y/宽/高（单位选英寸，px × 0.010417）。卡片用形状填充 + 4–6px 左侧色条（可直接用矩形叠加）。
7
插图表
插入 → 图表 → 簇状柱形图。右键设置数据系列格式，逐个改填充色为 #1B3A5C / #2E9BA6；开启数据标签；坐标轴文字改 #6B86A3。
8
自检
对照第 09 节清单逐条打勾。

路线 B · Keynote

Keynote 默认 16:9 为 1920×1080 → 全部 px 值 × 1.5（字号 × 1.5 后即为 pt 等效）。若用 2560×1440 则 × 2。主题色在「格式 → 高级 → 颜色」或自定主题中填入同样 hex；顶条 90px 高（60×1.5）。

路线 C · Figma / Canva / 即梦 / Gamma 等在线工具

画布设 1920×1080（×1.5）或 2560×1440（×2）。把第 02 节色板存为项目色板/品牌色，第 03 节字号阶梯存为文字样式（Text Styles），第 05 节卡片存为组件（Component）。这样换内容时只改文字，样式自动继承。

路线 D · 用开源工具链一键生成（推荐）

本规范已工程化为开源库 deep-ocean-slides：第 01–05 节的每个数值都是代码里的一个 token， 第 06 节 12 页坐标表就是 layouts.py 里的几何常量，deck 用 YAML 描述。 deepocean build deck.yaml -o out.pptx 直接产出可继续编辑的 PPTX， deepocean html deck.yaml 产出单文件网页版，deepocean check 按第 09 节清单自动自检。 详细用法见下一节。

09 · CHECKLIST交付前自检清单

母版与一致性

  • 顶条 / 标题位置 / 页脚 / 页码 全篇一致（封面与结尾可例外）
  • 刊名角标（如 ISR · 2025）位置全篇固定
  • 左右安全边距 40px 未被突破

视觉与信息密度

  • 每页主视觉 ≥ 内容区 30%；Hero 页有 ≥ 48px 锚点数字或 ≥ 40% 主视觉
  • 内容页卡片撑满，无大面积空白带；卡片填充率 ≥ 80%
  • 每页 ≥ 1 个视觉锚点（≥44px 元素 或 ≥40% 面积图）
  • 相邻两页视觉重量有差异（最大元素面积比 > 1.5:1 或版式结构不同）

色彩

  • 红色用量 ≤ 6%，金色 = 0
  • 无紫粉玫红、无橙绿大色块、无彩虹渐变、无纯黑大底
  • 内容区未使用深色实底或高饱和彩色实底
  • 强调色只出现在焦点元素上

文字

  • 正文 ≥ 13px（学术风下限 20px 适用于大段正文；卡片内小字不低于 11px）
  • 文字未溢出卡片、无断词异常
  • 深底白字 / 浅底深字，对比度 ≥ 4.5:1
  • 全篇只用 2 套字体家族、2 级字重

数据与图表

  • 每个数据页含：主图 + 洞察文字 + ≥1 个关键数字（"数据 + 判断"两段式）
  • 图表有数据标签；轴/图例色为中性灰，不抢戏
  • 所有数值可追溯到论文 Table / Figure，页脚标注来源
  • 无杜撰公式、虚构数据、编造引用

结构

  • 多卡页有"双重锚定"：一种物理连接（箭头/共享外框）+ 一种共享锚点（标题条/底部强调条）
  • 无 3D / 卡通 / 营销插画
  • 占位文字已清零
